# Factory examples (Checkpoint B snapshot)

One row per entity factory from a small connected build (profile `test`,
2026-10-02): an open AccessPolicy, Study S1 with DOI, PI, publication, VBR
and metadata, a trio from `make_family`, a baseline encounter, a Down
syndrome assertion, a blood draw, blood and derived DNA samples, an aliquot,
a CRAM with MD5 + SHA-1, a WGS assay, and a dataset. 85 non-reference rows
across 65 tables. Shown: the first row of each table by primary key, so it
isn't always the proband. Generated by a throwaway script; it will be
superseded by `docs/SCENARIO_TINY.md`.
